# Geography credits

## Photographs

Documentary-style pictures generated for this app (balloon, basket, aerial land, river, mountains, desert, lakes). No learner photos.

## Chart

`images/us-chart.svg` is an original schematic navigator chart (state marks, river strokes, mountain ticks, compass). It is not a survey plat and is not copied from a copyrighted atlas.

## Text

Original flight notes, quizzes, and songs. State names, capitals, and geographic feature names are public facts.

Native region names on the week-21 flight are standard geographic culture-area labels, written in original sentences.

## Sound

Web Speech API when available; WebAudio burner, wind, pin drop. No audio files.

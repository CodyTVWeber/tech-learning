# Reading — Garden

Theme: garden. Letter **sounds** first for `toddler` and `preschool` (never letter names as the first prompt). Picture-book reader for `early` and up.

Band via `?band=` or `hs.band`. Progress: `hs.progress.reading`.

## Bands

| Band | What happens |
| --- | --- |
| baby | Not linked |
| toddler / preschool | Sound-to-flower. Each choice shows a visible grapheme. TTS speaks the phoneme (`sss`, not “ess”). |
| early | Blends (sounds on the prompt, word after a correct tap), helper words *the* / *is*, then *Sam Sat*. *The Fig* unlocks after *Sam Sat*. |
| primary / upper | Garden reading timer + the same books + a few vocabulary blooms |

## Books

Original decodable text only. Tap a word to hear it. Play-page highlights as it reads. Image slots per page in `images.json`. Wave 2 adds the full set; final wave adds pictures.

## Sounds

Leaf rustle (try again), bee (prompt), bloom chime (correct), page turn.

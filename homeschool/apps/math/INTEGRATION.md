# Math — Treasure Voyage

Theme: pirate treasure voyage. Band via `?band=` or `hs.band`. Progress: `hs.progress.math`.

## Bands

| Band | What happens |
| --- | --- |
| baby | Not linked from infant home |
| toddler | Count coins 1–5, audio prompts |
| preschool | Numbers to 10, add to 10 |
| early | Add/sub within 100, place value |
| primary | Multiply / divide fact families |
| upper | Decimals, fractions, long operations |

Every session teaches a **technique**, then ends with **now do this on paper**.

## Files

See `assets.json`. Do not register a service worker when `document.documentElement.dataset.runner === "1"`.

## Sounds

Coin clink (correct), wood knock (try again), chest latch (reward), fifths (island complete). Mute is `hs.mute`.
